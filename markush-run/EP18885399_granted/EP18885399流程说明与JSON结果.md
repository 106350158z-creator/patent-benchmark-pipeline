### 2.5 OCR 和文本抽取

EPO PDF 很多是扫描件，直接文本抽取效果有限。因此采用两种方式：

| 文本文件后缀 | 生成方式 | 用途 |
|---|---|---|
| `_text.txt` | PyMuPDF 直接抽取 PDF 内嵌文本 | 对可复制文本 PDF 有效 |
| `_ocr.txt` | 本地 OCR 识别扫描 PDF | 对扫描版审查意见有效，是本案主要分析来源 |

示例 OCR 命令：

```powershell
python "$root\scripts\ocr-pdfs.py" `
  "$root\markush-run\EP18885399_granted\docs\19-05-2021_European_search_opinion_E57605779826DSU.pdf" `
  --zoom 1.6 `
  --overwrite
```

### 3.2 prior art 和实体异议来源

主要来自：

`19-05-2021_European_search_opinion_E57605779826DSU_ocr.txt`

该意见列出：

| 对比文件 | 内容 |
|---|---|
| D1 | WO2020/005860 |
| D2 | EP2628738 |
| D3 | EP1944303 |
| D4 | WO2011/051198 |
| D5 | EP2345328 |

审查员认为：

- D1 是中间文献，仅用于新颖性；
- D2、D3、D4、D5 与当时权利要求存在结构重叠；
- D3 和 D5 不仅具体实施例，而且整个重叠范围都可能破坏新颖性；
- D5 表 2 中 compounds 299-313 被点名；
- 由于缺乏共同的新颖技术特征，存在 Art.82 单一性问题；
- 若要证明创造性，需要相对最接近现有技术 D3 或 D5 提交定量比较数据；
- 还存在 Rule 43(4)、Art.84、Rule 42、说明书协调等形式和清楚性问题。

### 3.3 创造性克服来源

主要来自：

`02-08-2022_Annex_to_the_communication_L65A5Y3J1A7MR8A_ocr.txt`

该附件显示：

- D3 被视为 closest prior art；
- 当前申请的 Example 111 落入 D3 范围附近；
- 审查员要求与结构最接近先文比较；
- 申请人提交了当前化合物与 D3 化合物 209 的比较；
- 两者唯一结构差异是当前化合物多一个 F 原子；
- 当前化合物人肝细胞 viability 为 93%；
- D3 化合物 209 的人肝细胞 viability 为 77%；
- 因此技术问题被认可为提供降低哺乳动物细胞毒性的抗真菌剂；
- 在该基础上，inventive step 被认可。

### 3.4 评分逻辑

评分依据用户给定标准，并结合案件最终授权状态：

| 维度 | 评分逻辑 |
|---|---|
| 新颖性 | 早期被 D2-D5 明确质疑，但最终通过缩权克服并授权，因此不是满分，给 85 |
| 创造性 | 早期缺少比较数据，后续依靠与 D3 化合物 209 的毒性比较数据克服，给 80 |
| 支持/充分公开 | Art.123(2) 仅有小问题，未见 Art.83 异议，给 90 |
| 清楚性 | 有 Art.84/Rule 43/说明书协调问题，但授权前克服，给 80 |
| 单一性 | 早期因缺乏共同新颖技术特征被质疑，缩权后克服，给 80 |
| 适格性 | 未被质疑，EP 化合物/药物用途主题通常可适格，给 100 |

综合分按用户给定权重计算：

```text
aggregate_score =
新颖性 85 * 25%
+ 创造性 80 * 30%
+ 支持 90 * 15%
+ 清楚性 80 * 10%
+ 单一性 80 * 5%
+ 适格性 100 * 15%
= 85.75，四舍五入为 86
```

## 5. 结论

EP18885399.8 是一个典型的“先宽后窄、通过比较数据克服创造性”的化学 Markush 授权案例。

早期审查中，权利要求与多个先文 D2-D5 存在较强结构重叠，导致新颖性、单一性和创造性均有风险。申请人后续将保护范围缩窄到具体化合物，并提交相对 D3 最接近化合物 209 的人肝细胞毒性比较数据，证明额外 F 原子带来了降低哺乳动物细胞毒性的技术效果。该技术效果被审查员接受，案件最终进入授权。
