维度评分

维度分数分析理由
新颖性852021-05-19 欧洲检索意见指出 D1=WO2020/005860 仅作为中间文献用于新颖性；D2=EP2628738、D3=EP1944303、D4=WO2011/051198、D5=EP2345328 与当时的式(IV)化合物存在结构重叠，其中 D3/D5 不仅具体实施例而且整个重叠范围被认为破坏新颖性；D5 表2化合物299-313也被点名。后续权利要求缩窄为具体化合物 3-(3-(4-((6-fluoropyridin-2-yl)oxy)benzyl)isoxazol-5-yl)pyridin-2-amine 及其药学可接受形式，最终授权，说明新颖性异议已克服。
创造性80最接近现有技术在 2021-05-19 意见中被认为可为 D3=EP1944303 或 D5=EP2345328；审查员认为申请与 D2-D5 均用于抗真菌且结构重叠，客观技术问题应为提供改进抗真菌剂，但原始文件缺少相对最接近先文的定量比较数据。2022-08-02 附件确认申请人用当前化合物与 D3 第307页化合物209比较，唯一结构差异为额外 F 原子，比较试验显示当前化合物人肝细胞 viability 93% 而 D3 化合物209为77%，技术问题改定为提供降低哺乳动物细胞毒性的抗真菌剂，创造性被认可。
充分公开/支持902021-05-19 意见认为修改后的权利要求总体符合 Art.123(2) EPC，仅指出权利要求1 proviso 中 'hydrogen, is CH' 可能应改为 'hydrogen, X13 is CH'，并要求逐项标明原始公开支撑。后续授权文本被接受，未见 Art.83 充分公开异议。
清楚性802021-05-19 意见提出 Rule 43(4) 依附关系、'A'/'an' 单复数、incorporated by reference、spirit and scope、以及说明书与权利要求未协调等 Art.84/形式问题。2022-08-02 附件仍称前次第6-11点适用，但随后进入 Rule 71(3) 并授权，清楚性问题已通过文本修正克服。
单一性802021-05-19 意见认为由于 D2-D5 破坏当时共同新颖技术特征，申请缺乏统一的 common novel technical feature，存在 Art.82 单一性问题。最终缩窄为单一具体化合物及医药用途/组合物，授权时未保留单一性异议。
适格性100未被质疑；EP 案件为化学化合物、药物组合物和第二医药用途类型，未见 Art.52 EPC 适格性异议。

主要风险

  • D3/D5 与核心骨架高度重叠
  • 早期权利要求范围被 D2-D5 预期
  • 创造性依赖补充毒性比较数据
  • 需删除引用并协调说明书

建议动作

  • 缩权至授权化合物：加入 6-fluoropyridin-2-yloxy benzyl isoxazolyl pyridin-2-amine 具体结构
  • 在说明书中明确引用 D2-D5 并说明与各先文的结构差异
  • 保留并补强与 D3 化合物209的肝细胞毒性对比数据
  • 删除 incorporated by reference 和 spirit and scope 表述并重写说明书一致性段落
